## 1. Linux 基础指令（零基础视角）

### 1.1 系统区域设置（Locale）
```bash
# 诊断当前编码环境
locale

# 安装语言包管理工具
sudo apt update && sudo apt install locales

# 生成 UTF-8 编码支持（关键！ROS2 强制要求）
sudo locale-gen en_US en_US.UTF-8

# 永久保存设置（写入 /etc/default/locale）
sudo update-locale LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8

# 当前会话立即生效（无需重启）
export LANG=en_US.UTF-8

# 验证设置
locale
```
**核心认知**:

- `sudo` = 管理员权限（Super User Do）
    
- `apt` = 软件商店（update 刷新列表，install 安装）
    
- `>>` vs `>`: 双箭头是**追加**（安全），单箭头是**覆盖**（危险）
    
- `~/.bashrc` = 开机自动执行脚本（Run Commands）
    

**ROS2 为什么需要 UTF-8?**

- DDS 通信默认使用 UTF-8 编码字符串
    
- 防止日志输出出现 `����` 乱码
    
- 支持中文路径和注释
  
## 2. ROS2 环境配置

### 2.1 激活 ROS2 系统环境


```bash
source /opt/ros/humble/setup.bash
```

**作用解剖**:

- 告诉系统 ROS2 安装位置（`/opt/ros/humble`）
    
- 注册 `ros2` 命令到环境变量
    
- 设置编译工具链（colcon）路径
    
- **有效期**: 仅当前终端窗口（关窗失效）
### 2.2 开机自动配置（优化策略）


```bash
# 系统级环境（必需）
echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc

# 工作空间级环境（开发自定义包时需要）
echo "source /home/ros2/ws00_helloworld/install/setup.bash" >> ~/.bashrc
```

**分层加载机制（洋葱模型）**:

```plain
Layer 1: /opt/ros/humble (系统层 - 只读)
    ↓ 叠加
Layer 2: ~/ws00_helloworld/install (开发层 - 可写)
```

**关键原理**: 后加载的优先级高，开发层会**覆盖**系统层同名包（支持修改系统功能而不动原文件）

## 3. 首个 ROS2 节点体验

### 3.1 Turtlesim 仿真（官方示例）
```bash
# 终端1：显示节点（可视化）
ros2 run turtlesim turtlesim_node

# 终端2：键盘控制节点（输入）
ros2 run turtlesim turtle_teleop_key
```
**设计思想理解**:

- **多节点架构**: 显示与控制分离（单一职责原则）
    
- **分布式通信**: 两节点通过 DDS 自动发现，无需知道对方存在
    
- **话题通信**: 通过 `/turtle1/cmd_vel` 话题传递速度指令（发布/订阅模式）
    

**操作快捷键**:

- 方向键：移动
    
- `Q`：退出
    
- `R`/`T`/`G`/`F`/`V`/`B`：绝对朝向控制

## 4. C++ 节点开发实战（HelloWorld）

### 4.1 工作空间架构

```text
ws00_helloworld/                 # 工作空间（Workspace）
├── build/                       # 编译中间文件（临时，可删）
├── install/                     # 编译成果（可执行文件）
│   └── setup.bash              # 环境加载脚本（加载后才能run）
├── log/                         # 编译日志
└── src/                         # 源码目录
    └── pkg01_helloworld_cpp/    # 功能包（Package）
        ├── src/
        │   └── helloworld.cpp   # 节点源码
        ├── CMakeLists.txt       # C++ 编译配置（核心！）
        └── package.xml          # 包元信息/依赖声明
```

### 4.2 创建功能包

```bash
ros2 pkg create pkg01_helloworld_cpp \
  --build-type ament_cmake \
  --dependencies rclcpp \
  --node-name helloworld
```

**参数解析**:

- `--build-type ament_cmake`: C++ 必选，使用 ROS2 定制的 CMake 系统
    
- `--dependencies rclcpp`: 声明依赖 ROS2 C++ 客户端库
    
- `--node-name helloworld`: 自动生成可执行文件和模板代码
### 4.3 C++ 源码解剖（helloworld.cpp）

```cpp
#include "rclcpp/rclcpp.hpp"

int main(int argc, char ** argv)
{
  // 1. 初始化：连接 DDS 网络（"加入群聊"）
  rclcpp::init(argc, argv);
  
  // 2. 创建节点：分配唯一ID "helloworld_node"
  auto node = rclcpp::Node::make_shared("helloworld_node");
  
  // 3. 日志输出：带时间戳和节点名前缀
  RCLCPP_INFO(node->get_logger(), "hello world!");
  
  // 4. 释放资源：优雅断开 DDS 连接
  rclcpp::shutdown();
  return 0;
}
```
**关键概念**:

- `rclcpp` = ROS Client Library for C++
    
- `make_shared` = 智能指针（自动内存管理，防止泄漏）
    
- **生命周期**: init（出生）→ 工作 → shutdown（死亡）
### 4.4 编译系统配置（CMakeLists.txt 关键段）
```cmake
# 查找依赖
find_package(rclcpp REQUIRED)

# 生成可执行文件（源文件 → 二进制）
add_executable(helloworld src/helloworld.cpp)

# 链接 ROS2 库
ament_target_dependencies(helloworld "rclcpp")

# 安装规则（告诉 colcon 放哪）
install(TARGETS helloworld
  DESTINATION lib/${PROJECT_NAME})

# ROS2 宏（生成包索引，让 ros2 pkg list 能找到）
ament_package()
```
### 4.5 编译与执行流程

```bash
# 编译（在工作空间根目录执行）
colcon build

# 加载编译后的环境（关键！让系统找到新编译的程序）
. install/setup.bash
# 或 source install/setup.bash

# 运行节点
ros2 run pkg01_helloworld_cpp helloworld

# 预期输出：
# [INFO] [1713012345.123] [helloworld_node]: hello world!
```

**编译型 vs 解释型**:

- C++ 需要 `colcon build` 生成机器码（.cpp → 可执行文件）
    
- Python 不需要编译，直接解释运行（后续对比学习）

## 6. 进阶原理补充（文档/视频未深入）

### 6.1 DDS 分布式通信架构

- **无中心化**: ROS2 没有 ROS1 的 Master 节点，采用 DDS 自动发现
    
- **类比**: 像微信群，节点加入网络（`init`）后自动收发消息，无需知道对方 IP
    
- **影响**: 你今天写的 `rclcpp::init()` 实际上是在启动分布式通信引擎
### 6.2 节点生命周期（完整版）


```cpp
rclcpp::init();              // 出生：连接 DDS，分配资源
auto node = make_shared();   // 工作：创建上下文（今天要加的节点通常这里直接结束）
rclcpp::spin(node);          // 保持存活（循环处理回调，后续学习）
rclcpp::shutdown();          // 死亡：释放端口，断开连接
```

**关键区分**:

- **一次性节点**: 你今天写的（执行完就退出）
    
- **常驻节点**: 后续学习的（需要 `spin` 保持运行）
    

### 6.3 ament 构建系统 vs CMake

- **关系**: `ament_cmake` = 标准 CMake + ROS2 定制扩展
    
- **ament 额外功能**:
    
    - `ament_package()`: 生成 ROS2 包索引
        
    - `ament_target_dependencies`: 自动处理 ROS2 库链接
        
    - 统一安装路径规则（`install/` 目录结构）
        

### 6.4 节点命名与网络寻址

- `"helloworld_node"` 不仅是变量名，更是 **DDS 网络中的域名**
    
- ROS2 自动转换为唯一参与者 ID（类似 MAC 地址 + 端口）
    
- **命名冲突**: 同名节点会自动加后缀，但应避免
