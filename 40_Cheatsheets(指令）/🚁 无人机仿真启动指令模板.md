# 🔍 前置环境检查（每个终端都要执行）
```bash
# 1. ROS2 基础环境
source /opt/ros/humble/setup.bash

# 2. 工作空间环境（关键！否则找不到自定义包）
source ~/competition_ws/ros2_ws/install/setup.bash

# 3. 网络配置（必须保证统一）
```

# 🆘 故障速查表

| **现象**                       | **可能原因**      | **解决命令**                                             |
| ---------------------------- | ------------- | ---------------------------------------------------- |
| `No module named 'px4_msgs'` | 环境未 source    | `source ~/competition_ws/ros2_ws/install/setup.bash` |
| `image_bridge` 终端空白          | 正常日志过滤        | `ros2 topic echo /camera --once` 验证数据                |
| Gazebo 窗口黑屏                  | 模型加载错误        | 确认使用 `gz_x500_depth` 模型                              |
| 无法进入 Offboard 模式             | Agent 启动顺序错误  | 必须先启动终端 1 (Agent)，再启动终端 2 (PX4)                      |
| `topic list` 看不到 `/camera`   | Domain ID 不统一 | `echo $ROS_DOMAIN_ID` 检查是否均为 42                      |
